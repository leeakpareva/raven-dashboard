# RAVEN Dashboard - AI & Software Education Platform

An interactive multi-page Streamlit application featuring data-driven insights on AI's impact on software development and the RAVEN AI education platform.

## Overview

This educational dashboard visualizes the growing crisis in software development as AI tools create a generation of developers who lack fundamental skills. Through data visualization and real-world examples, it illustrates the economic and technical implications of over-reliance on AI coding assistants.

## Features

### 📊 Crisis Dashboard
- **Interactive Data Visualizations** using Plotly
- **Real-World Case Studies** of AI-related failures
- **Economic Impact Analysis** of technical debt
- **Skills Gap Metrics** from industry surveys
- **The RAVEN Approach** - Educational AI methodology (WHAT/HOW/WHY)

### 🚀 RAVEN Platform
- **Investor Deck** - Complete 9-slide presentation
- **Product Specifications** - Detailed technical overview
- **360-Degree Learning Approach** - Educational methodology
- **Market Focus** - Target audiences and applications
- **Open-Source Innovation** - Accessibility and customization

## Key Topics Covered

1. The Automation Avalanche - AI adoption statistics
2. The Fundamentals Crisis - Skills gap data
3. Real-World Catastrophes - Banking, Healthcare, Startup failures
4. Economic Impact - $2.7 trillion in technical debt
5. The Path Forward - AI as enabler, not crutch

## Running Locally

```bash
# Clone the repository
git clone https://github.com/leeakpareva/raven-dashboard.git
cd raven-dashboard

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```
