# RAVEN Dashboard - AI & Software Education Platform

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://raven-dashboard-research.streamlit.app/)

An interactive multi-page Streamlit application featuring data-driven insights on AI's impact on software development and the RAVEN Terminal education platform.

## Overview

This educational dashboard visualizes the growing crisis in software development as AI tools create a generation of developers who lack fundamental skills. Through comprehensive data visualization and real-world examples, it illustrates the economic and technical implications of over-reliance on AI coding assistants.

## Features

### 📊 Crisis Dashboard
- **Interactive Data Visualizations** using Plotly Express
- **Real-World Case Studies** of AI-related failures and breaches
- **Economic Impact Analysis** - $2.7 trillion in technical debt
- **Skills Gap Metrics** from industry surveys and research
- **Code Reading Crisis** - Declining comprehension abilities
- **Security Vulnerabilities** - 312% increase in AI-code breaches
- **First-Time Quality Economics** - Cost multipliers for fixing bugs
- **Knowledge Erosion Timeline** - Skills decay without practice

### 🚀 RAVEN Terminal Platform
- **Educational Philosophy** - WHAT/HOW/WHY methodology
- **Core Capabilities** - AI-powered learning toolkit
- **Programming Languages** - Python, JavaScript, TypeScript, Java, SQL
- **Open Source Initiative** - Empowering developers through education
- **Learning Approach** - Fundamentals-first coding education

## Key Insights & Statistics

- **28%** - Time developers spend reading code in 2024 (down from 58% in 2018)
- **67%** - Junior developers who cannot debug without AI assistance
- **312%** - Increase in security breaches from AI-generated code since 2022
- **$4.45M** - Average cost of a security breach
- **1000x** - Cost multiplier for fixing bugs in post-release vs design phase
- **78%** - Annual compound rate of technical debt growth

## Running Locally

```bash
# Clone the repository
git clone https://github.com/leeakpareva/raven-dashboard.git
cd raven-dashboard

# Install dependencies
pip install -r requirements.txt

# Run the application
streamlit run app.py
```

The app will be available at `http://localhost:8501`
